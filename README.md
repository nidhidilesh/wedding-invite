# Nidhi & Jay — Wedding Invitation Website

A responsive, multi-section wedding invitation made with plain HTML, CSS and JavaScript. No framework or build step is required.

## Run it
Open `index.html` in a modern browser. For the best experience, you can also serve this folder with a local static server.

## What's included
- Consistent cream, teal, antique-gold and floral visual theme inspired by the supplied invitation and background references.
- Scroll-reactive peacock, lotus and petal illustrations, reveal animations, mobile navigation and back-to-top control.
- The eight functions grouped across three celebration days exactly as provided.
- Google Maps links for Hotel Hemal Gardens and Azzaro Resorts & Spa.
- Calendar-download buttons for each function and a countdown to 31 January 2027 at 10:00 AM.
- Supplied bride and groom photos, converted to browser-friendly JPEGs where needed.

## Fonts
The CSS requests `New Icon Script`, `Halimum`, and `XB Niloofar` first, with web-safe / Google Font fallbacks. Those named fonts are not bundled because no font files were supplied. If you have licensed `.woff2` files, place them in `assets/fonts/` and add `@font-face` declarations in `css/style.css`.

## Note on outfit styling
The supplied couple photos are used as provided; the website does not digitally change clothing in the photographs.


## Font note
The script font is Halimun only. For the exact font, add a licensed `Halimun.woff2` file to `assets/fonts/Halimun.woff2`. Without that local font file, the browser uses its generic cursive fallback. New Icon Script and Great Vibes are not used. The family and closing/countdown sections have been removed as requested.
